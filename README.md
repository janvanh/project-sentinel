# Project Sentinel

**Status:** Pre-implementation. No functional software exists yet. This repository currently contains project specifications and governance documents only.

## What This Is

Project Sentinel is a privacy-focused, local-first software platform designed to help individuals exercise their privacy rights against companies, data brokers, marketing databases, and other organizations that store or process personal information.

It is built around a small set of non-negotiable principles:

- The user owns and controls their data.
- No mandatory online account exists.
- No central database of user identities exists.
- Automation assists the user, it never replaces the user's decisions.
- Companies receive only the minimum information required for a given request.
- The community maintains and improves the shared company database.

Project Sentinel is designed as a serious security and consumer privacy application, not a convenience tool. Every architectural decision in this project is made in that order: legal compliance first, then privacy, then extensibility, then automation, then transparency, then community maintenance, and speed last.
