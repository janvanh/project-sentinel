\chapter{Project Overview}

This project is a privacy-focused, local-first software platform designed to help individuals exercise their privacy rights against companies, data brokers, marketing databases, and other organizations that store or process personal information.

\begin{sentinelnote}[Design Principle]
Automation only assists the user, it never replaces the user's decisions.
\end{sentinelnote}

This project aims zo provide an alternative to centralized privaacy removal services by ensuring that:

\section{Goals}
\begin{itemize}
  \item The user owns and controls their data.
  \item No mandatory online account exists.
  \item No central database of user identities exists.
  \item Automation assits users rather than replacing their decisions
  \item companies receive only the minimum informations required
  \item the community maintains and improves company information
\end{itemize}

The software is designed as a serious security and consumer privacy application.
