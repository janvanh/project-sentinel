\chapter{E-Mail Integration}

The software connects to existing email providers.

Supported:
\begin{itemize}
	\item Gmail
	\item Proton Mail
	\item Outlook
	\item generic IMAP/SMTP
\end{itemize}
Users should be encouraged to create a dedicated email account only for privacy requests and then link that account to the software. Users should not use their day-to-day email address.

\section{E-Mail Features}
The system should:
\begin{itemize}
	\item send requests
	\item receive replies
	\item organize conversations
	\item track deadlines
	\item detect verification requests
	\item maintain request history
\end{itemize}
