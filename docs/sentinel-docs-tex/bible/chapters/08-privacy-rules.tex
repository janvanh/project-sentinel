\chapter{Privacy Rules}
Users can create, manage, and share custom rules.
Examples:
\begin{itemize}
	\item Never automatically upload government ID
	\item Always request confirmation before sending documents
	\item Never send phone numbes unless required
	\item Always remove metadata from files
	\item Require approval for high-risk requests
\end{itemize}

The default rules are very strict. This ensures the user will have full security, and only information that the user opts-in to will be shared.
