\chapter{Company Database}

The company database is a core component.
It contains:
\begin{itemize}
	\item company information
	\item privacy contacts
	\item legal requirements
	\item request methods
	\item supported frameworks
	\item automation capabilities
\end{itemize}

\section{Company Records}
Every company record must contain minimum information required for privacy requests.
Required:
\begin{itemize}
	\item company name
	\item website/domain
	\item privacy contact
	\item request method

\end{itemize}
Additional information:
\begin{itemize}
	\item privacy URLs
	\item email addresses
	\item addresses
	\item supported laws
	\item identity requirements
	\item deadlines
	\item request history
	\item automation methods
\end{itemize}
