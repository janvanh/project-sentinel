\chapter{Installation}
Installation should be as simple as possible.
Target experience:

\begin{enumerate}
	\item Install application
	\item Create encrypted local vault
	\item Configure privacy preferences
	\item Begin using software
\end{enumerate}

The system should manage dependencies automatically where possible.
