\chapter{AI Policy}

AI is not part of the core application.

Possible AI features must be:
\begin{itemize}
	\item optional
	\item local only
	\item open source
	\item permission controlled
\end{itemize}
No external AI communication is allowed. All AI integrations must stay within the program itself.
