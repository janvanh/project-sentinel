\chapter{Plugins}

Plugins allow community expansion.

Examples:
\begin{itemize}
	\item specialized company automation allowing more complicated requests to be automated
	\item optional AI tools, for example to categorize emails more effectively
	\item additional integrations
\end{itemize}

Plugins must:
\begin{itemize}
	\item be open source
	\item be reviewed
	\item be signed
	\item be reproducible
	\item use permission controls
\end{itemize}
Default plugin permissions:
\begin{itemize}
	\item[!] No access.
\end{itemize}

Plugins must explicitly be granted access by the user.
