\chapter{Privacy Principles}

\section{Data Minimization}
The system must always send the minimum amount of information required.

Example:

If a company only requires an email address, the software should not send:
\begin{itemize}
	\item phone number
	\item address
	\item date of birth
	\item government identification
\end{itemize}

\section{No Central User Database}
The project must never maintain a database containing:
\begin{itemize}
	\item user identities
	\item personal information
	\item request histories
	\item private documents
\end{itemize}

All sensitive information belongs to the user.
