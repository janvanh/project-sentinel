\chapter{Privacy Score}

Before requests are sent, the user should see a privacy impact score.

\textbf{LOW RISK}
\begin{itemize}
	\item Email only
\end{itemize}

\textbf{HIGH RISK}
\begin{itemize}
	\item Government ID required
	\item Manual approval required
\end{itemize}


The score informs the user but does not prevent action.
