\chapter{Document Protection}

Before transmitting documents, the software should:
\begin{itemize}
	\item remove metadata
	\item remove EXIF information
	\item remove hidden properties
	\item remove unnecessary content
\end{itemize}

Supported features:

\begin{itemize}
	\item redaction
	\item cropping
	\item watermarking
\end{itemize}
