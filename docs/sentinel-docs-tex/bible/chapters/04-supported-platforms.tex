\chapter{Supported Platforms}
Inital supported platforms are:
\begin{itemize}
	\item Windows
	\item Linux
	\item macOS
\end{itemize}

In the future it is possible that an \emph{Android/iOS} companion application will be developed.

The first priority is desktop functionality. In later stages of the project, a webserver hosted version could be possible, where no user data leaves the browser and is only processed within the users personal electronic device. To save and/or change anything, a database would be downloaded through said web-interface, giving maximum privacy to the user and ensuring no data is transmitted through networks.
