\chapter{Core Philosophy}

\section{Local-First Architecture}

All personal user information remains on the user's own device.

The software must not require:

\begin{itemize}
	\item cloud storage
	\item external user accounts
	\item centralized identity databases
	\item mandatory telemetry
	\item tracking systems
\end{itemize}

Any future hosted version must preserve privacy by ensuring user data remains encrypted and inaccessible to service operators.

\section{User-Controlled Automation}

The software is an automation tool, not an independent decision maker.
The user always controls:
\begin{itemize}
	\item which companies are contacted
	\item which requests are sent
	\item which information is shared
	\item whether documents are uploaded
	\item whether actions are approved
\end{itemize}

The system should automate repetitive tasks, while keeping final authority with the user.

\section{Priority Order}
The project priorities are:
\begin{enumerate}
	\item Legal Compliance
	\item Privacy
	\item Extensibility
	\item Maximum automation
	\item Transparency
	\item Community maintanence
	\item Speed
\end{enumerate}
