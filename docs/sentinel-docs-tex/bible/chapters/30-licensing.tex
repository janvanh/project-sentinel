\chapter{Licensing}

License Direction: Source-available, non-commercial (e.g. PolyForm-Noncommercial-1.0.0 or a comparable non-commercial license).

\section{Decision Rationale}

The project's two goals, full source transparency and a hard block on commercial exploitation, cannot both be satisfied by a license that meets the formal Open Source Definition (OSD). The OSD's "no discrimination against fields of endeavor" clause specifically prohibits restricting commercial use; this is the line that separates "open source" (OSI-recognized licenses such as MIT, Apache-2.0, GPL/AGPL) from "source-available" licenses (such as BUSL or PolyForm-Noncommercial).
Because preventing commercial exploitation is a non-negotiable priority for this project (see Section 31), the project deliberately chooses a source-available, non-commercial license over an OSI-approved open-source license.

\section{What This Means in Practice}
The full source code is publicly available to read, audit, fork, and modify, with no restriction on personal, educational, research, or nonprofit use.
Community contribution remains fully open.
No individual, company, or derivative project may generate revenue from this codebase, or any part of it, without a separate agreement with the project.
This license technically does not qualify as "open source" under the OSI's formal definition, and the project will not claim otherwise. It will be described accurately as "source-available" or "free and open, non-commercial," with this document's rationale made publicly visible so the distinction is never misrepresented to users or contributors.
This decision is intentional and explained publicly, rather than left ambiguous, so that the project's transparency claims (Section 31) remain accurate and defensible.

The exact license text (e.g. PolyForm-Noncommercial-1.0.0 vs. a custom non-commercial license) will be finalized during Phase 1, but the direction, source-available, non-commercial, is now settled.
