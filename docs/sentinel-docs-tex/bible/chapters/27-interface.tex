\chapter{Interface}

The application uses one advanced interface. This interface consists of the following main sections:

\begin{itemize}
	\item Requests
	\item Companies
	\item Identity Profiles
	\item Rules
	\item Plugins
	\item Logs
	\item Settings
\end{itemize}

A command-line interface (CLI) may be added later. This will likely be limited to UNIX-based operating systems.
