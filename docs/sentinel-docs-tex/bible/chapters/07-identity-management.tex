\chapter{Identity Management}
Users can create unlimited identity information.
Supported information for 1.0:
\begin{itemize}
	\item names
	\item email addresses
	\item phone numbers
	\item addresses
	\item previous addresses
	\item business identities
	\item historical identities
\end{itemize}

\section{Identity Profiles}
Users can organize information into profiles.
Examples:

\begin{itemize}
	\item Personal Identity
	\item Business Identity
	\item Previous Address
	\item Old Email Identity
	\item Custom Profiles
\end{itemize}

Companies only receive information from selected profiles
