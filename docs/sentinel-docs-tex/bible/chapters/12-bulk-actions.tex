\chapter{Bulk Actions}

The software supports bulk privacy actions.
Examples:
\begin{itemize}
	\item Remove me from all known people-search websites.
	\item Remove me from advertising databases.
	\item Remove me from data brokers.
	\item Bulk requests should be grouped intelligently.
	\item Similar requests may be approved together.
	\item Different requests should be separated.
	\item Users can create custom groups.
\end{itemize}
