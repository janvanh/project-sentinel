\chapter{Local and Global Database}

Each installation has:
\begin{itemize}
	\item \textbf{Global Database}
		\begin{itemize}
			\item Community maintained
		\end{itemize}
	\item \textbf{Local Database}
		\begin{itemize}
			\item User controlled
		\end{itemize}
\end{itemize}

The local database allows users to store companies that are not yet globally approved.
