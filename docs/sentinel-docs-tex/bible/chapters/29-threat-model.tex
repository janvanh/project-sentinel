\chapter{Threat Model}

The software protects against:
\begin{itemize}
	\item centralized data collection
	\item cloud provider compromise
	\item stolen encrypted databases
	\item accidental information oversharing
	\item malicious plugins
	\item malicious or compromised database/software update pushes (see Section 26)
\end{itemize}


The software cannot protect against:
\begin{itemize}
	\item malware already controlling the device
	\item companies legally requiring information
	\item users exposing their own passwords
\end{itemize}
