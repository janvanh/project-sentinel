\chapter{Security Philosophy}

Security should be community driven. The project encourages:
\begin{itemize}
	\item code review
	\item vulnerability reports
	\item ethical security testing
	\item penetration testing
\end{itemize}
Users are explicitly encouraged to test the software responsibly to improve security.
