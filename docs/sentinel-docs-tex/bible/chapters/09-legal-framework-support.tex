\chapter{Legal Framework Support}
The system should support major privacy frameworks worldwide.
Included from version 1.0 should be:
\begin{itemize}
	\item GDPR
	\item UK GDPR
	\item CCPA/CPRA
	\item US state privacy laws
\end{itemize}

The system should expand support over time. Near-term expansion targets, to be designed for from the start so the Phase 9 template engine does not require a later redesign, include:
\begin{itemize}
	\item Canada (PIPEDA)
	\item Brazil (LGPD)
	\item Australia (Privacy Act)
\end{itemize}
