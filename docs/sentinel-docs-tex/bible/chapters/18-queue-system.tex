\chapter{Queue System}

Background Operations require task queue.

The preferred initial solution is an embedded, SQLite-backed queue.

This choice preserves the local-first and simple-installation principles established in Sections 2.1 and 5: no external database server needs to be installed, configured, or maintained by the user, and the queue lives inside the same local application footprint as the rest of the vault-adjacent data.

Used for:
\begin{itemize}
	\item sending emails
	\item scheduled checks
	\item database synchronization
	\item document processing
	\item background tasks

\end{itemize}
This reduces dependencies and improves local security.
