\chapter{Project Identity}

The project should be positioned as a serious security and consumer privacy application.

It should be:
\begin{itemize}
	\item professional
	\item trustworthy
	\item transparent
	\item privacy-focused
\end{itemize}

It should not become:
\begin{itemize}
	\item surveillance software
	\item a data collection service
	\item a marketing platform
\end{itemize}

And no exceptions can be made by any entity reusing the entire codebase, or parts thereof.
